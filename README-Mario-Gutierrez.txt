In-Class 1 v3

1. What surprised you most about the widget tree/state/lifecycle stuff once you saw it in the app?

Honestly the TabController thing surprised me, I didn't realize TabBar and TabBarView don't actually talk to each other, they're both just hooked up to the same controller and that's what keeps them in sync.

2. Which concept took the longest to click, what made it click?

Lifecycle stuff (initState/dispose) took me the longest. It clicked when I actually thought through what happens if you never call dispose, like the controller just sits there in memory doing nothing useful. Once I pictured that it made way more sense why you have to clean up.

3. What part of the GitHub workflow felt least familiar?

I didn't have a partner for this so doing a pull request by myself felt kind of weird since normally someone else is supposed to review it. I just went through the diff myself before merging like someone else would.

4. If you rebuilt this tomorrow what would you do differently?

I'd probably answer the questions while actually looking at the code instead of trying to remember it after, made things way easier to explain.
