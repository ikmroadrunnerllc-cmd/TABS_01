Bug 1: Scope Failure

Symptom: Pressing any one button sank all four buttons at once.

// Removed from _ControlDeckScreenState:  bool isPressed = false;
class TactileButton extends StatefulWidget { ... }
class _TactileButtonState extends State<TactileButton> {
  bool isPressed = false;   // each button owns its own flag
}

Why it works: The press flag lived on the screen and all four buttons read it. Moving it into each button's own State means a press only rebuilds and sinks that one button.

Bug 2: Silent Mutator

Symptom: Dragging the slider didn't move the thumb or update the percentage.

onChanged: (newVal) => setState(() => powerLevel = newVal),

Why it works: The old code changed powerLevel without calling setState(), so Flutter never redrew. Wrapping the assignment marks the screen dirty, so the slider, label and Energy Level card redraw.

PASTE: screenshot of the slider moved with Energy Level showing the new value.

Bug 3: Geometry Inversion

Symptom: Buttons popped up when pressed and looked flat at rest.

boxShadow: isPressed
    ? [ Offset(2, 2) / Offset(-2, -2), blurRadius: 4 ]    // sunken
    : [ Offset(8, 8) / Offset(-8, -8), blurRadius: 16 ],  // raised

Why it works: The two shadow branches were swapped. Small, tight shadows make a surface look pressed in and large, soft ones make it look raised, so swapping them back makes the button sink when pressed.

PASTE: screenshot of a button mid-press looking sunken.

Bug 4: Event Race

Symptom: The action fired on first touch and the button never visibly stayed down.

onTapDown: (_) => setState(() => isPressed = true),
onTapUp: (_) {
  setState(() => isPressed = false);
  widget.onPressed();
},
onTapCancel: () => setState(() => isPressed = false),

Why it works: onTapDown called both the press and release handlers, so the action fired before the user let go. Now touch-down only sinks the button, lift-up releases it and fires the action, and cancel resets it without firing.
