Round 2: State Destruction Derby

Our fixed code is in lib/round2_bug_hunt_fixed.dart. We kept the original // 🐛 BUG # comments so each fix is easy to find.

Bug 1: Scope Failure

Problem: pressing one button made all four buttons go down.

// removed bool isPressed = false; from _ControlDeckScreenState
class _TactileButtonState extends State<TactileButton> {
  bool isPressed = false;
}

Why it works: there was only one isPressed on the screen and every button used it. Now each button has its own, so only the one you press goes down.

Paste screenshot: one button pressed, the others still up.

Bug 2: Silent Mutator

Problem: moving the slider didn't update anything on the screen.

onChanged: (newVal) => setState(() => powerLevel = newVal),

Why it works: the value was changing but Flutter didn't know it needed to redraw. Putting it inside setState() makes the slider and the percentage update.

Paste screenshot: slider moved and Energy Level showing the new number.

Bug 3: Geometry Inversion

Problem: the buttons looked like they popped up when pressed instead of going down.

boxShadow: isPressed
    ? [ Offset(2, 2), Offset(-2, -2), blurRadius 4 ]
    : [ Offset(8, 8), Offset(-8, -8), blurRadius 16 ],

Why it works: the two shadow lists were swapped. A small shadow looks pushed in and a big shadow looks raised, so we switched them back.

Paste screenshot: a button being pressed and looking pushed in.

Bug 4: Event Race

Problem: the action happened as soon as you touched the button, and the button never stayed down.

onTapDown: (_) => setState(() => isPressed = true),
onTapUp: (_) {
  setState(() => isPressed = false);
  widget.onPressed();
},
onTapCancel: () => setState(() => isPressed = false),

Why it works: onTapDown was running both the press and the release code at once. Now touching only pushes the button down, letting go runs the action, and dragging off cancels it.
